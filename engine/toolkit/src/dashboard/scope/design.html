2 · Anatomy (frozen, cursors on, trigger set)

Displays are for output, wells are for input: the screen only shows (traces, axes, legend values, cursor readout); every control sits in the grey caption under it.

1 2 3 4 5 6
  1. 1
    Legend

    One entry per channel: its colour and line sample, the source port (pid.u, from the wire, no naming), the value and unit. Live: latest. Cursors on: the value at cursor 2. Click an entry to hide that trace (struck through).

  2. 2
    Axes

    Time on x. One y axis per unit: the first unit left, a second unit right (here rad and N·m). Ticks in muted mono, a dashed zero line. Autoscale fits what is visible.

  3. 3
    Trigger

    T on the right edge at the level, a ▼ on the top edge at the trigger point. Drag T to change the level.

  4. 4
    Cursors

    Two vertical cursors, dragged by their tabs. The strip at the bottom of the screen reads t1, t2, Δt, 1/Δt and Δ for each channel.

  5. 5
    Readout strip

    Only while cursors are on. Copy from ⋯ › Copy cursor values.

  6. 6
    Caption

    Name, the state in words (live, frozen, armed, triggered), the mode choice and keys. A toggle that is on sits in brackets, never filled. Keys that don't fit fold into ⋯.

3 · Modes: [ time ] xy fft

One Scope, three ways to look at the same channels. The mode is part of the Board layout (saved with the project), not a block param, so it changes during a run without touching the graph.

time, trigger auto on gen.y rising at 0, position 20%: a periodic signal stands still.
xy: the first channel on x, the others on y. The trail is the window; the head is a dot.
fft: magnitude in dB of the visible window (Hann), log frequency. The biggest peak per channel is marked and read in the legend.

4 · Sizes and before a run

The grid's sizes, no new ones. Smaller sizes drop chrome, never data: normal shows corner ranges instead of axes and keeps only ⋯ in the caption.

normal 2×1: traces, corner ranges, one-line legend; caption is name, state, ⋯.

large 2×2 (default): axes, legend, mode choice, cursors, ⋯.
xlarge 3×3: every key (see frame 1).
Before a run: the placeholder frame, dashed and grey, naming its inputs.

9 · Channel colours and draw styles

Eight colours in a fixed order, made for the black screen (it is black in both themes, so one list serves both). A channel keeps its colour when others are hidden or removed. No red: red means failed. Channels 1–4 are solid and stay apart for every pair, even for colour-blind readers. Channels 5–8 are dashed and 9–16 dotted, so traces that cross never rely on colour alone. Draw style is under ⋯: [ line ] line+points points smooth.

line (default): straight segments between samples, what the run sent and nothing more.
line+points: the same line with a ring on every sample, so you see the sample rate.
points: samples only, for sparse or event data.
smooth: monotone cubic through the samples, never overshooting them. Cursors and values read the samples, not the curve.
