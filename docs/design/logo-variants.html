Paperboat mark · small size and a water ripple

Two decisions: when the mark is too small for its 2-unit pixels, switch to a smooth geometric variant; and let the signal-coloured water ripple now and then. These are mockups for comparison — the production renderer is unchanged.

3 · Water ripple (animation)

The mark’s water is the only coloured part, and it means “live”. A small ripple passes through it now and then: 1–2px of travel, 1.4s, on the existing ease. Four candidate behaviours. Press “replay” to see one pass.

W1 · Dot ripple

each water dot lifts in sequence; the boat stays still. Pure, no layout shift.
idle every ~18s · on hover · while a run is live

W2 · Ripple + boat bob

the ripple lifts the boat ~1.5px as the crest passes under it.
the boat is a child, so it bobs as a unit

W3 · Boat tilt

the boat rocks ~2° as the wave passes under it.
rotation around the hull’s centre

W4 · Travelling wave on a line

the water line itself undulates; a crest travels left → right. Small variant only.
animates the SVG d attribute; needs a JS fallback in Firefox

Idle · always on (long cycle)

a ripple every ~18s, ripples for ~7% of the cycle, then rests. No JS, no per-frame work.
this is the “once in a while” behaviour the request asks for

Reduced motion

under prefers-reduced-motion, all of the above collapse to 0ms (the tokens already do this). The mark never moves on its own in that case.
shown here as a still frame

5 · Implementation notes

  • Threshold. Pixel mark at height >= 18 (or 20); geometric below it. DESIGN.md currently says “below 16px use the favicon” — propose changing to “below 18px use the geometric variant” so the favicon (brand palette) stays reserved for the browser tab / app icon.
  • Logo.tsx. Add a Small component (or a variant="geometric" prop) whose SVG uses smooth vector paths with shapeRendering="geometricPrecision". Keep the same 62×42 viewBox so the bar layout is unchanged; the hull trapezoid and sail triangle land in the same place.
  • Favicon. Stays pixel art in the brand palette (it is an app icon at 64px, never small enough to need the geometric form).
  • Ripple. Implement as a CSS keyframe on the water group, not JS: animation: ripple 18s var(--ease) infinite with a 7% active window, gated by @media (prefers-reduced-motion: reduce) { animation: none; }. Run-linked variant: toggle a class on the wordmark when run.started arrives and remove it on run.finished.
  • Idle vs. live. Idle ripple every ~18s is the “once in a while” behaviour requested. While a run is live, switch to the faster ripple (W2, 1.4s) so the mark says “live” in the signal colour — which is already what the water is.
  • Motion budget. The ripple moves 1–2px, well under the “no layout shift” rule; transform only, no width/height animation.
